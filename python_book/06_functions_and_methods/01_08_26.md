# arguments and parameters
Arguments are objects passed to a function during invocation. Parameters are placeholders for the objects that will be passed to the function when it is invoked.

parameter scope is the function it is passed to as an argument

# Function Return values
all python functions evaluate to a value, by default this is `None` - the implicit return value. the explicit return value is defined with `return`.

functions that always return a boolean value are `predicates`.

```python
def is_digit(char):
    if char >= '0' and char <= '9':
        return True

    return False
```
